## 📌 Overview
Predict future weather parameters such as temperature, humidity, and wind speed using **Long Short-Term Memory (LSTM) networks** on historical meteorological data.  
The project demonstrates **time-series forecasting** with deep learning and preprocessing techniques.

---

## 🛠️ Features
- Preprocesses and cleans meteorological datasets  
- LSTM-based sequence modeling for forecasting  
- Model evaluation using **RMSE** and **MAE** metrics  
- Handles missing data and normalization  
- Visualizes predicted vs actual weather trends
